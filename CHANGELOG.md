# Изменения

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.1.0] — 2026-07-27

Первая версия MVP.

### Продукт

* Telegram-бот как launcher Mini App с командами `/start`, `/menu`, `/help`,
  `/stats`, `/privacy`. Упрощённый режим прямо в чате, когда Mini App не
  подключён: случайные вопросы с разбором, работа над ошибками, вопрос для
  mock interview, статистика.
* Mini App из 16 экранов: главная, настройка, план подготовки, теория, урок,
  практика, mock interview, кейсы, словарь, библиотека, вакансия, истории,
  профиль, история, поиск, о приложении.
* Онбординг: выбор трека, самооценка по 11 областям, дата собеседования,
  дневная цель.
* План подготовки из 24 шагов с зависимостями и проверяемыми условиями
  завершения.
* Интервальное повторение (система Лейтнера, 6 коробок) для вопросов,
  терминов, открытых вопросов и кейсов.
* Семь режимов практики: быстрый тест, тренировка, финальный экзамен,
  повторение, работа над ошибками, слабые темы, по темам.
* Mock interview с рубрикой самооценки и режимом полной сессии по блокам
  настоящего собеседования.
* Практические кейсы в два этапа: сначала своя попытка, затем эталонный разбор.
* Экран вакансии с gap-анализом: статусы требований, доказательства из
  портфолио, пробелы, следующие шаги.
* Story bank: 12 шаблонов STAR.
* Единый поиск по урокам, терминам, материалам, вопросам, кейсам и шагам плана
  с поддержкой русского, английского и синонимов.
* Достижения, карта активности, история с графиком готовности.

### Расчёт готовности

* Пять взвешенных блоков: знания и SRS 35%, mock interview 25%, кейсы 20%,
  словарь 10%, план и регулярность 10%.
* Четыре ограничителя: нет полной сессии mock — потолок 74%, меньше трёх
  кейсов — 79%, слабая критическая тема — 69%, низкое покрытие обязательных
  тем — 64%.
* Самооценка из настройки не участвует в расчёте.
* Незаполненный трек не получает процента готовности.
* Расчёт чистый и воспроизводимый: одинаковый вход даёт одинаковый выход.
* План к дате учитывает работу всех типов, а не только число тестов.

### Инфраструктура

* Sync API на FastAPI и SQLite: авторизация по HMAC-подписи Telegram
  `initData`, слияние без потерь, атомарный read-merge-write, ограничение
  частоты и размера запроса, удаление данных пользователя.
* Правила слияния продублированы в клиенте и на сервере с обязательным тестом
  паритета.
* Service worker: network-first для кода и страниц, stale-while-revalidate для
  статики, `/api/*` мимо кэша.
* Инструменты: валидация контента (более 2300 проверок), генератор данных
  приложения с проверкой свежести, аудит источников по сети, поиск дублей,
  отчёт о покрытии.
* CI: три задачи — Python, JavaScript, гигиена репозитория. Секрет-скан,
  проверка отсутствия `.env` и пользовательских данных, проверка на следы
  референсного проекта.
* Развёртывание: systemd-юниты с песочницей, пример конфигурации Caddy,
  скрипты обновления, бэкапа с проверкой восстановления и проверки живости.

### Тесты

* Python: контент (22), слияние и паритет (24), API (36), бот (30),
  безопасность (20), нагрузка (2) — 134 теста.
* JavaScript: SRS, прогресс, готовность, слияние, поиск, service worker,
  навигация — 7 наборов проверок без npm-зависимостей.

### Известные ограничения

* Свободный текст ответа не оценивается: без настоящей языковой модели такая
  оценка была бы имитацией. Вместо этого разбор, эталон и рубрика самооценки.
* Наполнен один трек из четырёх.
* Один язык интерфейса.
* Сервер доверяет присланному прогрессу: серверной проверки нет.
* Бэкапы хранятся на той же машине.
